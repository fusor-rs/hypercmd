# hypercmd identity

hypercmd follows [fusor's identity](https://github.com/fusor-rs/fusor/blob/main/apps/landing/BRANDING.md):
the same palette, wordmark typeface and two-piece construction.

The mark is a terminal prompt in two pieces: an upper chevron and a lower cursor.
The cursor's slanted ends run parallel to the chevron's lower arm, echoing the
diagonal cuts of fusor's F. The wordmark is Lexend SemiBold, outlined to paths.
All logo SVGs contain vector paths, with no embedded raster images, external
fonts, or scripts.

Use the symbol alone for small icons and avatars. Use the dark-background
horizontal logo where the page background is dark; it keeps the symbol in color
and switches the wordmark to warm white.

| Role | Color |
| --- | --- |
| Chevron | Vermilion `#DF5036` |
| Cursor and interface accent | Oxide `#A83228` |
| Light background and reversed artwork | Warm white `#FAF9F6` |
| Wordmark and monochrome artwork | Charcoal `#272A2C` |

Preserve the proportions, the gap between the two pieces, and clear space.
